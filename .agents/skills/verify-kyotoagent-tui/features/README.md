# TUI verification map

Build the real binary, run Doctor, and use a fresh evidence directory for each run. The helper owns its servers and terminal; it never attaches to the user's session.

- [Saved servers](servers.md): pairing, server picker, Local, private config, and restored drafts.
- [Remote models](models.md): the selected server's live catalog and unavailable model exclusion.
- [Rendering](rendering.md): empty pane, braille progress, action labels, waiting, and stable YOLO.

Record the entry point exercised with the evidence. Verify additional entry points when a change touches them. Capturing the example renderer proves terminal layout; the isolated live TUI proves connection behavior.
